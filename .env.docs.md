# Environment Variables

## Required

### OPENAI_API_KEY
Your OpenAI API key from https://platform.openai.com/api-keys

**Example:**
```bash
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxx
```

## Optional

### OPENAI_MODEL
The OpenAI model to use for generation.

**Default:** `gpt-4o-mini` (recommended - fast and cheap)

**Options:**
- `gpt-4o-mini` - Fastest and cheapest ($0.15/1M input tokens) ✅ RECOMMENDED
- `gpt-4o` - More capable but 10x more expensive ($3.00/1M input tokens)
- `gpt-3.5-turbo` - Older, cheaper model but less capable

**Example:**
```bash
OPENAI_MODEL=gpt-4o-mini
```

**Note:** GPT-5 is not yet available. Use `gpt-4o-mini` for the best balance of cost and quality.

## Cost Estimates

With `gpt-4o-mini`:
- Average app generation: ~2,000-4,000 tokens
- Cost per generation: $0.0003-$0.0006 (less than $0.001!)
- 1,000 apps: ~$0.50

The default model is already extremely cheap!
